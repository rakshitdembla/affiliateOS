# AffiliateOS

Private affiliate management platform: product catalog, public collection pages, and Instagram comment-to-DM automation.

- `apps/desktop` — Tauri + React + TypeScript admin app (macOS)
- `apps/api` — Cloudflare Worker (Hono) with D1 + R2
- `packages/shared` — TypeScript contracts shared by both
- Public storefront (`apps/web`) arrives in Phase 3.

Status: **Phase 4 (Instagram integration) — awaiting Meta app setup** — see [CHANGELOG.md](CHANGELOG.md). Start with [DEVELOPMENT.md](DEVELOPMENT.md).
